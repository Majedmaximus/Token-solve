شفّر نسختك داخل المتصفح.

اختيار الملف يقرأه محليًا فقط؛ هذه الصفحة لا ترفعه إلى سيرفر. بعد تحميل أدوات الصفحة يمكنها العمل دون اتصال. لا تدخل كلمة مرور GitHub أو عبارة استرداد محفظة: اختر عبارة جديدة خاصة بهذه النسخة. فقدان العبارة وكل البدائل يعني عدم القدرة على فك التشفير.

التشفير AES-256-GCM مع اشتقاق مفتاح PBKDF2-SHA256. الأداة ليست مدققة بشكل مستقل، وثقتك بأمان جهازك والمتصفح ومصدر الصفحة أساسية. لا تحفظ الملفات أو العبارة تلقائيًا، ولا يوجد مفتاح استرداد عند المساعد. احتفظ بنسختين مستقلتين واختبر فتحهما.

سيرفر الاستضافة يستقبل طلب تحميل الصفحة وملفاتها العادية فقط وقد يسجل عنوان IP؛ لا ترسل الأداة اسم ملفك أو محتواه أو العبارة إليه. الخصوصية والحدود.
